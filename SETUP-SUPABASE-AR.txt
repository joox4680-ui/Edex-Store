إعداد قاعدة بيانات Edex Store (الخطة المجانية)

1) افتح https://supabase.com وأنشئ مشروعاً جديداً.
2) من SQL Editor اختر New query، والصق محتويات supabase-schema.sql ثم اضغط Run.
3) من Authentication > Users أنشئ مستخدم الإدارة ببريدك وكلمة مرور قوية.
4) انسخ User UID من قائمة Users.
5) في SQL Editor نفّذ الأمر التالي بعد استبدال UUID بالـ UID الحقيقي:
   insert into public.admin_users(user_id) values ('ضع-USER-UID-هنا');
6) من Project Settings > API انسخ Project URL و anon/public key.
7) افتح supabase-config.js وضع القيم مكان النصوص التجريبية. استخدم anon/public فقط، ولا تستخدم service_role.
8) ارفع مجلد edex_store كاملاً إلى استضافة الموقع.

ما تم تجهيزه:
- حفظ الطلبات في قاعدة البيانات قبل فتح واتساب.
- قراءة الأسعار من قاعدة البيانات.
- تسجيل دخول الإدارة عبر Supabase Auth.
- حفظ أسعار الخدمات من لوحة الإدارة.
- RLS تمنع الزوار من قراءة الطلبات، وتسمح للإدارة المعتمدة فقط بقراءتها وتعديلها.
- جداول جاهزة للكوبونات.

الأمان والاختبار:
- لا ترسل كلمات المرور أو مفاتيح Supabase السرية في المحادثة.
- المفتاح المسموح في المتصفح هو anon/public فقط مع RLS.
- لا تستخدم service_role في الموقع إطلاقاً.
- بعد الإعداد اختبر الطلب كزائر، ثم الدخول كإدارة، وتأكد أن الزائر لا يستطيع قراءة الطلبات.
- حالياً لوحة الأسعار وإدارة الدخول مبدئية؛ شاشة متابعة الطلبات وإدارة الكوبونات ستحتاج واجهة إضافية لاحقة.
